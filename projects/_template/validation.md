# Validation

## Acceptance checklist

- [ ] Required dimensions and tolerances verified.
- [ ] Sketches have the intended constraint state.
- [ ] Document recomputes without unexpected errors.
- [ ] Geometry is valid for the intended use.
- [ ] Part/body relationships and model tree are understandable.
- [ ] Manufacturing or assembly constraints are checked.
- [ ] Required exports open correctly and preserve expected scale/units.
- [ ] Deliverables match `project.md`.
- [ ] Unverified assumptions and remaining risks are documented.
